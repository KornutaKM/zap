# Zap — Telegram-бот для подбора автозапчастей

MVP Telegram-бота, который ведёт пользователя от автомобиля к каталогу деталей и предложениям поставщиков.

## Текущий UX

Бот остаётся обычным Telegram-ботом — без Mini App. Основной сценарий построен на reply-кнопках, inline-кнопках и обычных сообщениях.

Если автомобиль сохранён, главное меню показывает:

- 🔎 Найти запчасть
- 📚 Каталог
- 🛠 ТО и обслуживание
- 🚗 Мой автомобиль

Если автомобиля нет:

- 🚗 Добавить автомобиль
- 📚 Каталог по модели
- 🔎 Найти по артикулу

Команды `/catalog`, `/search`, `/garage` остаются как резервный способ управления.

## Каталог по марке и модели

Можно написать прямо в чат:

```text
BMW X3
```

Для известных в demo-справочнике моделей бот сначала предлагает поколение:

```text
BMW X3 E83 · 2003–2010
BMW X3 F25 · 2010–2017
BMW X3 G01 · 2017–2024
BMW X3 G45 · 2024–
```

После выбора открывается каталог:

```text
Каталог
├── ТО и фильтры
├── Тормозная система
├── Подвеска и рулевое
├── Двигатель
├── Охлаждение
└── Электрика
```

Сейчас demo-резолвер поколений содержит несколько семейств BMW, Toyota, Volkswagen и Skoda. Если модель отсутствует в локальном справочнике, бот не блокирует пользователя и открывает общий каталог по введённой модели.

## Поиск

Если автомобиль выбран, можно просто написать:

```text
передние колодки
масляный фильтр
амортизаторы
```

или нажать кнопку «Найти запчасть».

По известному артикулу поиск работает и без автомобиля:

```text
GDB1956
```

В этом случае бот явно указывает, что совместимость с автомобилем не проверялась.

## Результаты

Demo-версия ранжирует предложения и показывает:

- ⭐ лучший баланс;
- 💰 самый дешёвый;
- 🚚 самый быстрый.

Цены и применимость пока демонстрационные.

## Гараж

Через «Добавить автомобиль» или `/garage_add` пользователь вводит:

1. марку;
2. модель;
3. год;
4. VIN — опционально.

VIN в сообщениях маскируется: показываются только последние 4 символа.

Сейчас хранится один активный автомобиль на пользователя.

## Архитектура

- `app/main.py` — Telegram handlers и FSM;
- `app/ui.py` — кнопки и форматирование сообщений;
- `app/catalog.py` — дерево групп запчастей;
- `app/vehicle_parser.py` — распознавание марки/модели из текста;
- `app/vehicle_catalog.py` — demo-справочник поколений;
- `app/providers.py` — интерфейс источников и demo-провайдер;
- `app/domain.py` — доменные модели и ранжирование;
- `app/db.py` — SQLite/SQLAlchemy.

Exist и Autodoc пока представлены заглушками. Для production предполагаются официальные API, партнёрские фиды или согласованные B2B-интеграции.

## Запуск

Python 3.12+

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
cp .env.example .env
```

В `.env`:

```env
BOT_TOKEN=...
DATABASE_URL=sqlite+aiosqlite:///autoparts.db
```

Запуск:

```bash
python -m app.main
```

## Проверки

GitHub Actions выполняет:

```bash
python -m compileall -q app
pytest -q
```

Проверяются ранжирование, структура каталога, распознавание автомобиля, поколения и UI-форматирование.
