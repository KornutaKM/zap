# Autoparts Telegram Bot — MVP

MVP Telegram-бота для поиска автомобильных запчастей и навигации по каталогу автомобиля.

## Что уже есть

- гараж пользователя: марка, модель, год, VIN (опционально);
- общий каталог модели с группами и подгруппами;
- ввод автомобиля обычным сообщением, например `BMW X3 G01`;
- команда `/catalog` для автомобиля, сохранённого в гараже;
- вариант `/catalog BMW X3 G01` без предварительного сохранения;
- поиск детали обычным текстом или по артикулу;
- единый интерфейс провайдеров;
- demo-провайдер с разными предложениями для тормозов, фильтров, подвески, охлаждения и электрики;
- выбор «лучший баланс», «самый дешёвый», «самый быстрый»;
- SQLite;
- заглушки под будущие официальные интеграции Exist/Autodoc;
- GitHub Actions для автоматического запуска тестов.

> Цены и применимость в текущем MVP демонстрационные. Бот пока не обращается к реальным магазинам и не подтверждает совместимость по VIN.

## Запуск

Python 3.12+

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
cp .env.example .env
```

В `.env` укажите токен, полученный у BotFather:

```env
BOT_TOKEN=...
DATABASE_URL=sqlite+aiosqlite:///autoparts.db
```

Запуск:

```bash
python -m app.main
```

## Сценарий 1 — гараж и точечный поиск

1. `/start`
2. `/garage`
3. Добавить автомобиль.
4. Написать `масляный фильтр`, `передние тормозные колодки` или артикул вроде `GDB1956`.
5. Получить варианты по цене/сроку.

## Сценарий 2 — каталог автомобиля

Пользователь может просто написать:

```text
BMW X3 G01
```

Бот открывает дерево:

```text
Каталог
├── ТО и фильтры
├── Тормозная система
├── Подвеска и рулевое
├── Двигатель
├── Охлаждение
└── Электрика
```

После выбора группы появляются подгруппы и демонстрационные предложения.

Можно также использовать:

```text
/catalog
/catalog BMW X3 G01
```

Если автомобиль задан только маркой и моделью, каталог считается общим. Перед реальной покупкой конкретного артикула будущая версия должна уточнить год/модификацию/VIN.

## Архитектура каталога

Дерево категорий находится в `app/catalog.py`. Telegram-интерфейс оперирует короткими ID категорий, а конечные узлы содержат нормализованный поисковый запрос. Это позволит позже заменить demo-данные реальным каталогом применимости без переделки интерфейса бота.

Провайдеры цен реализуют единый интерфейс `PartsProvider`. Сейчас подключён `MockProvider`; `ExistProvider` и `AutodocProvider` оставлены как точки подключения официальных API или партнёрских фидов.
