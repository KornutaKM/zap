# Autoparts Telegram Bot — MVP

MVP Telegram-бота для поиска автомобильных запчастей.

## Что уже есть

- гараж пользователя: марка, модель, год, VIN (опционально);
- поиск детали обычным текстом или по артикулу;
- единый интерфейс провайдеров;
- mock-провайдер с демонстрационными предложениями;
- выбор "лучший баланс", "самый дешёвый", "самый быстрый";
- SQLite;
- заглушки под будущие официальные интеграции Exist/Autodoc.

> Цены в MVP демонстрационные. Бот пока не обращается к реальным магазинам.

## Запуск

Python 3.12+

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
cp .env.example .env
```

В `.env` укажите токен, полученный у BotFather:

```env
BOT_TOKEN=...
DATABASE_URL=sqlite+aiosqlite:///autoparts.db
```

Запуск:

```bash
python -m app.main
```

## Сценарий

1. `/start`
2. `/garage`
3. Добавить автомобиль
4. Написать `масляный фильтр`, `передние тормозные колодки` или артикул вроде `GDB1956`
5. Получить три варианта.
